# Full-Size SUV Fuel Economy Analysis

## Project Overview

This project analyzes fuel economy trends for full-size SUVs from 2015 to 2025, focusing on the Toyota Sequoia and comparing it with the Chevrolet Tahoe, Ford Expedition, and GMC Yukon.

## Tools Used

- Python (Pandas, Matplotlib) – data cleaning, filtering, analysis, and visualization
- MySQL – querying and aggregating the processed data
- Power BI – interactive dashboard and DAX measures
- Jupyter Notebook – exploratory data analysis

## Key Findings

- Toyota Sequoia average combined fuel economy increased from 14.5 MPG in 2022 to 21 MPG in 2023.
- This represents approximately a 44.83% improvement in combined MPG.
- Estimated annual fuel cost for the Toyota Sequoia decreased by approximately 30.59% from 2022 to 2023.
- The 2023 redesign created a major shift in the Sequoia's fuel economy trend compared with previous model years.

## Project Workflow

1. Loaded and explored vehicle fuel economy data using Python and Pandas.
2. Cleaned and filtered the dataset for full-size SUV competitors from 2015–2025.
3. Analyzed fuel economy trends and annual fuel costs.
4. Exported the processed dataset for further analysis.
5. Used MySQL to query and aggregate fuel economy data.
6. Built DAX measures and an interactive Power BI dashboard.
7. Compared the Toyota Sequoia with the Chevrolet Tahoe, Ford Expedition, and GMC Yukon.
